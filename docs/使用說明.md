# 使用說明

把 SAP 匯出的 Excel／CSV／txt 檔匯進 SQL Server。不需要裝 Python，
不需要開任何開發工具，雙擊 `excel-to-db.exe` 就好。

---

## 第一次使用（只要做一次）

### 1. 確認電腦有 ODBC 驅動程式

程式一打開如果跳出「缺少 ODBC 驅動程式」，就是還沒裝。請 IT 安裝
**ODBC Driver 17 for SQL Server**（18 也可以），裝完重開程式。

這是 Windows 的系統元件，沒辦法包進這個資料夾裡，只能另外裝。

### 2. 填連線設定

在 `excel-to-db.exe` 旁邊找到 `.env.example`，**複製一份改名成 `.env`**
（把 `.example` 拿掉），用記事本打開，填這兩行：

```
SQL_SERVER=主機名稱或IP,1433
SQL_DATABASE=資料庫名稱
```

用自己的 Windows 帳號連的話，`SQL_USER` 和 `SQL_PASSWORD` 兩行留空。
要用 SQL 帳號就填進去。

存檔，重開程式。

---

## 每次匯入

### 1. 準備資料夾

**一張表一個子資料夾**，資料夾名字就是要建的資料表名字：

```
我的資料\
  EKKO\
    1月.xlsx
    2月.xlsx
  EKPO\
    全部.xlsx
```

同一個子資料夾裡的檔案**欄位必須一模一樣**，程式會把它們接成一張表。

### 2. 掃描

打開程式 → 「瀏覽…」選到最外層那個資料夾（上例是 `我的資料`）→ 按**掃描**。

上半部會列出找到幾張表、每張幾列、有沒有問題。
點一張表，下半部會列出每個欄位判成什麼型別、前幾筆長什麼樣。

### 3. 檢查型別（重要）

程式會自己判斷每欄是文字、數字還是日期。判得不對就**點那一欄，從下拉選單改**，
改完會自動記住，下次掃同一張表就沿用。

大部分時候不用改。真的要注意的只有兩種：

- **黃色標示的欄位**：整欄是整數、但欄名不在已知清單裡，程式保守地當成文字了。
  如果那欄真的要拿來加總，改成 `INT` 或 `DECIMAL(18,2)`。
- **單號被當成數字**：不應該發生，但如果看到前面的 0 不見了，改成 `NVARCHAR(255)`
  並回報給開發者。

### 4. 選寫入模式（**最重要的一步**）

| 模式 | 做什麼 | 什麼時候用 |
|---|---|---|
| `replace` | **把資料表整個刪掉重建** | 第一次匯入，或要整批換掉 |
| `append` | 接在現有資料後面 | 後續補資料 |

> **注意：`replace` 會把那張表原本的資料全部刪掉，救不回來。**
> 補資料一定要選 `append`。

### 5. 按「開始匯入」

幾十萬列要跑好幾分鐘，畫面下方會顯示進度（讀取中、寫入 5 萬／30 萬列…）。
跑完會顯示各表結果。

## 遇到問題

### 「找不到 ODBC 驅動程式」

見上面第一次使用的第 1 步。

### 「連線失敗」

`.env` 裡的伺服器名稱或資料庫名稱打錯，或這台電腦連不到那台伺服器。
先確認能不能用 SSMS 連上同一台。

### Excel 說「我們發現部分內容有問題，要盡可能嘗試復原嗎」

**這是檔案本身壞了，不是程式的問題。** 常見原因：

- 從 SAP 下載到一半中斷 → **重新下載一次**
- SAP 匯出時選到「Excel（MHTML 格式）」→ **改選「試算表」**
- SAP 匯出時選到 HTML → **改選「試算表」或「Unconverted」**

把那個檔案放進資料夾掃描一次，程式會直接告訴你它到底是什麼格式，
例如：

```
壞掉.xls 其實是 MHTML（Excel 的網頁封存格式）。
本工具讀不了 MHTML。在 SAP 匯出時改選「試算表」而不是「Excel（MHTML 格式）」
```

### 「欄位不一致」

同一個子資料夾裡的檔案欄位不一樣。把欄位不同的檔案分到別的子資料夾。

### 「指定的型別放不下」

你（或之前的人）把某欄的型別指定死了，但實際資料放不進去。
訊息會指名是哪一欄、建議改成什麼。照著在下拉選單改掉就好。

### 其他錯誤

程式旁邊會產生 `import.log`，把整段訊息連同 `import.log` 一起給開發者。

## 給開發者：診斷檔案格式

```
python sniff.py "檔案路徑" --what
```

認內容不認副檔名，會回報是 zip、OLE2、SpreadsheetML、MHTML、HTML、
純文字，還是被截斷的半個檔。這支只用標準函式庫，複製單一檔案到任何
一台有 Python 的機器就能跑。
